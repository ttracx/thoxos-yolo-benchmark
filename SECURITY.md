# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it
privately to security@thox.ai. Do not open a public issue.

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- Acknowledgement within 48 hours
- Initial assessment within 5 business days
- Fix or mitigation depending on severity

## Security Measures

- All inference runs in-browser — no server-side data exposure
- No external API calls or analytics
- No cookies or tracking
- Custom model uploads use blob URLs (local only, never uploaded)
